## 1. 宿主适配层

宿主差异全部收敛在 `src/adapter.ts`（工具 consumer 与 provider 通过它取宿主能力），核心库不感知宿主：

| 适配点 | 实测落地（2026-10 审计回写） | 适配函数 |
|---|---|---|
| 数据目录 | `GRAPHRAG_DATA_DIR` → `$DSH_HOME/graphrag` → `~/.dsh/graphrag`（配置 dataDir 优先；QiLin 3.x 通道复用同链——实测无独立 home 约定，原 `~/.qilin/graphrag` 分支未采用） | `resolveDataDir(configured, env)` |
| 调用者身份 | `exec.agent.session.{id, header.cwd}` 防御性解构（双引擎同构） | `callerFrom(exec)` |
| 审批挂钩 | agent scoped `tools/pre-execute`（先 next 后升级，仅 allow 时拦截；纯函数 `approvalDecision` 便于单测） | tool.ts 内 `approvalDecision` |
| 公告注入 | `ctx.systemPrompt.section({order:210})` | tool.ts 内 ANNOUNCEMENT |
| LLM 辅助调用 | `ctx.llm.stream()`（鸭子型防御读取 + 失败码映射 + RATE_LIMIT 指数退避 + 空闲/总时长双护栏）；模型路由：显式配置 > 会话路由跟随（`watchSessionRoutes` 监听 `session/event`） | `llmCompleterOf(ctx, route, policy)` |
| 视觉链路 | 附件服务 `saveImages` + image 内容块（创建期一次性解析，缺席 → null 降级） | `visionCompleterOf(ctx, route, policy)` |
| 能力探测 | 服务存在性非严格读取（`reflect.get(name, false)`），不做版本硬依赖 | `llmServiceOf(ctx)` / `capabilities(ctx)` |

探测失败的行为矩阵（实测形态）：无 `llm` → 词法/遍历/已有图谱检索可用，索引/摘要/global LLM 打分按词法兜底或 `NO_PROVIDER` 指引（抽取模型无来源时给出两条可操作路径）；无 `tools` → 工具面不挂载；无 `webServer` → rpc 行 pending 不影响工具面；`seam` 缺席 → provider/tool 静默降级并告警。

## 2. package.json（关键面；实测形态，2026-10 审计回写）

- `exports`：`.` / `./provider` / `./tool` / `./rpc` / `./client`（各带手写薄 d.ts `types` 面，`src/dts/` 随 build 拷贝进 `lib/`）+ `./package.json`；原 `./config` 入口由 rpc+client 形态取代。
- `files`：`lib / cordis.patch.yml / README.md / LICENSE / release`；`engines.node >= 22.19`；`dsh`/`qilin` 双 `bundle.patch` + `client.platform: 'web'` + `client.inject`（十项客户端服务，软探测）。

## 4. 构建设计（`scripts/build.mjs`）

- esbuild，入口 = index/provider/tool/rpc 四服务入口（bundle 到 `lib/*.js` + sourcemap）+ `src/client/index.tsx`（browser CJS 包 `window.__ModuleLoader__.load` 模块表包装器，`__bundleRequire` 软取宿主能力如 MarkdownText）；
- external：`@deepseek-ai/*` + `zod`（本仓对宿主零运行时导入，`@qilin/*` 无需列）；
- **产物提交进仓**（`lib/` 不 gitignore）：安装期零构建，pnpm 无需构建许可；
- **薄 d.ts 手写层**（`src/dts/` → `lib/*.d.ts` 随 build 拷贝，exports 挂 types）——消费者是宿主运行时，类型面以 seam 契约为准；
- `smoke-plugin.mjs`：模拟宿主装载走完 apply，断言 seam 注册、provider 注册 + estimate 契约、**工具注册面恰为 5**、公告段存在、seam 缺席静默降级（审批门断言由 tool.test.ts 的 pre-execute 单测承担）。
