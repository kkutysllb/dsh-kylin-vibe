## 版本信息

| 项 | 值 |
|---|---|
| 版本 | 0.1.6 |
| 日期 | 2026-11-15 |
| tag | `v0.1.6` |

本版本只修一个阻断性缺陷：**DSH 桌面端升级到 0.2.2-rc.2/rc.3 后，安装或升级
本插件会失败，宿主日志报 `ctx.agents.roots is not a function or its return value
is not iterable`，`graphrag_*` 五工具与侧边栏面板全部不可用。**

---

## 修复

### 安装/启动即失败：`ctx.agents.roots()` 在 DSH 0.2.2 上已不存在

**症状**：DSH 桌面端（实测 `0.2.2-rc.3`）经插件管理安装或升级本插件后插件不生效，
宿主报 `ctx.agents.roots is not a function or its return value is not iterable`；
同一份 0.1.5 在升级前的 DSH 与 QiLin 桌面端正常。回退 DSH 版本即恢复。

**根因**：DSH 上游提交 `b3d4933f39f`（2026-10-23，*refactor(subagent): own live
lineage outside core agent registry*，随 `dsh-v0.2.2-rc.2` 发布）把子代理血缘由
subagent 服务拥有，从 `AgentRegistry` 删除了 `roots()` 与 `ownerAgent`，只保留
`get()` / `list()`。本插件 `src/tool.ts` 的 `apply()` 用
`for (const root of ctx.agents!.roots())` 枚举根 agent，在**激活期同步抛出**
TypeError；插件管理器把 `apply` 抛错视为安装失败，于是整行未挂载——工具、公告段、
审批门、RPC 路由全部缺席。`inject: ['agents']` 只保证服务存在，不保证方法存在，
所以错误没有更早暴露。

**修复**：新增宿主注册表兼容层（`src/tool.ts` 的 `readLiveAgents()` /
`isMountableAgent()`）：

- 读法优先级 `roots()` → `list()` → 空表。QiLin 3.x 与老版 DSH 用 `roots()`，
  DSH ≥0.2.2-rc.2 用 `list()`（该版本注册表只含根 agent，子代理不再注册）。
- 两种读法都抛错（注册表已释放/宿主变体）时**降级为空表**，由 `agent/created`
  事件兜底挂载——激活期永不抛错。
- 单个 agent 挂载失败只告警（`ctx.logger?.warn`），不升级为激活失败。
- `roots()` 可用时仍按根集过滤，子代理不会重复挂载 5 个工具（QiLin 语义不变）。

**回归测试**：`tests/tool.test.ts` 新增 4 项——① 只有 `list()` 的 DSH 形状激活
不抛错且 5 工具照常挂载；② `roots()`/`list()` 都抛错时 apply 不抛错、事件兜底
挂载；③ 注册表没有任何读法（`agents: {}`）时不抛错；④ `roots()` 存在时子代理
不重复挂载。测试桩 `hostStub()` 现可参数化五种注册表形状
（`roots` / `list` / `both` / `throwing` / `none`）。

## 兼容性与升级说明

| 宿主 | 注册表形状 | 本版本行为 |
|---|---|---|
| DSH ≥ 0.2.2-rc.2（含 0.2.2-rc.3 桌面端） | `get()` + `list()`，无 `roots()` | `list()` 枚举，全部可挂载 ✅ |
| DSH < 0.2.2-rc.2 | `roots()`（+`list()`） | `roots()` 根集过滤 ✅ |
| QiLin 3.0.x / 3.1.x | `roots()` + `list()`，含子代理 | `roots()` 根集过滤 ✅ |

- 升级方式：`dsh plugin --profile <name> add dsh-kylin-vibe`（或桌面端插件管理
  「更新」），装到 0.1.6 后恢复；已因 0.1.5 失败而回滚的 profile 直接重装即可。
- npm 主渠道由维护者 `npm publish` 后生效；本地验证可用
  `npm pack` 产物或 `link:` 安装。
